# 🥘 PantryPal AI

**Your kitchen remembers, so you don't have to.**

PantryPal is a smart kitchen companion that helps users keep track of pantry ingredients, discover what they can cook, manage personal recipes, and build smarter grocery lists.

## Current Features

- 📦 Pantry inventory management
- ⚠️ Low-stock detection
- 🥬 Expiry / use-soon tracking
- 📖 Personal recipe storage
- 🍳 Recipe availability checking
- ⚖️ kg ↔ g and L ↔ ml conversion
- ✅ Cook recipe and automatically update pantry
- 🛒 Grocery list management
- 🔄 Purchased groceries automatically update pantry
